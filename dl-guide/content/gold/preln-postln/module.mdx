# Pre-LN versus Post-LN stability

## Historical question and bottleneck

[On Layer Normalization in the Transformer Architecture](https://arxiv.org/abs/2002.04745) (Xiong et al., 2020) is the primary reference. The original question motivating this module is how to compare normalization placement and warmup using matched-depth language models and gradient traces. The practical bottleneck for this exercise is explicit: Track gradient norms divergence and warmup with identical token order. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`PreLN: x_next=x+F(LN(x)); PostLN: x_next=LN(x+F(x)).`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **tinyshakespeare**. Output: **[N,T] tokens -> [N,T,V] logits**. Optimize or report **bpc** in the **minimize** direction. Track gradient norms divergence and warmup with identical token order.

This is a draft skeleton: reference training and task-specific tests are not implemented. The explicit stub must not be mistaken for a finished model.

- Track gradient norms divergence and warmup with identical token order.
- Never fit statistics on validation labels or mix held-out examples into training.
