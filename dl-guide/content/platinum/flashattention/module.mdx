# Tiled exact attention

## Historical question and bottleneck

[FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness](https://arxiv.org/abs/2205.14135) (Dao et al., 2022) is the primary reference. The original question motivating this module is how to implement tiled online-softmax attention in PyTorch with optional Triton; verify outputs and gradients before timing. The practical bottleneck for this exercise is explicit: Online log-sum-exp block correction; test gradients before speed measurements. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`m_new=max(m_old,max(scores)); l_new=exp(m_old-m_new)*l_old+sum exp(scores-m_new); rescale the output accumulator likewise.`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **attention-equivalence**. Output: **forward(q,k,v,mask=None) -> attention output**. Optimize or report **attention_max_error** in the **minimize** direction. Online log-sum-exp block correction; test gradients before speed measurements.

This is a draft skeleton: reference training and task-specific tests are not implemented. The explicit stub must not be mistaken for a finished model.

## Controlled experiment

Compare materialized attention with tiled attention at increasing sequence lengths. Keep split, seed, optimizer schedule and training budget fixed unless that factor is the experimental variable. Report raw quality, wall time and parameter count, not an unsupported superiority claim.

## Pitfalls and checks

- Online log-sum-exp block correction; test gradients before speed measurements.
- Never fit statistics on validation labels or mix held-out examples into training.
- Check shape and finite outputs before interpreting quality; an unrelated baseline cannot satisfy the intended mechanism.
- Draft targets and safety limits have not been GPU-calibrated. No pass threshold is advertised.
