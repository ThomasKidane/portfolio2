# ResNet: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
h'=\operatorname{ReLU}(h+F(h)),\\ \frac{\partial(h+F(h))}{\partial h}=I+J_F(h)
\end{aligned}
$$

Here h is the input, F the residual branch, I the identity, and J the branch Jacobian. The derivative shown is before the final ReLU; identity addition requires matching shapes.

learn a residual correction around an identity shortcut rather than an unconstrained replacement. A branch applies conv–batchnorm–ReLU–conv–batchnorm, then adds the input before ReLU. The stem and both blocks preserve spatial size and width 16, so the identity shortcut is valid without projection. Global average pooling makes the final classifier independent of spatial dimensions. This is a tiny two-block residual network, not ResNet-18/50.

Read [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

A bounded executable reference is provided. Imports and model classes live inside solve(data) so a learner can copy the function into the editable notebook cell without hidden helpers. The reference returns dlguide.Submission; the notebook owns P.budget() and grading.

Reference training is deliberately bounded. Inspect the mechanism-specific schedule described above and in solution.py; CPU smoke tests establish executability, not convergence or benchmark quality. LeNet and ResNet use 24 Adam minibatches with learning rate 0.01 and clipping at 5.

## Task-specific evaluation

Dataset: **mnist**. Model contract: **[N,1,28,28] -> [N,10] logits**. Metric: **accuracy**, direction **maximize**. Tiny two-block teaching network; zero branch recovers identity followed by ReLU.

No calibrated passing threshold is available.



## Required ablation

Remove identity shortcuts while preserving both branch convolutions. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
