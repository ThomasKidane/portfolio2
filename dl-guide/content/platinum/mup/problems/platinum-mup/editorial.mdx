# Maximal-update parameterization: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
\operatorname{RMS}(\Delta h^{(n)})=\Theta(1)\quad\text{as }n\to\infty\quad\text{(illustrative target)}
\end{aligned}
$$

Here n is width and Delta-h a feature change after an optimizer step; RMS is root-mean-square magnitude and Theta-one means nonvanishing, bounded scale with width. This is an illustrative maximal-update scaling target, not the full muP prescription: initialization, learning rates, readout scaling, parameter roles, and optimizer must be specified together.
