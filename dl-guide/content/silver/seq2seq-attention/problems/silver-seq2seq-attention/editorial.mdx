# Seq2Seq with attention: derivation and implementation notes

## The mechanism

Read [Neural Machine Translation by Jointly Learning to Align and Translate](https://arxiv.org/abs/1409.0473) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

This is an explicit implementation stub. Architecture adaptation, dataset loader and reference training are not implemented. solution.py raises NotImplementedError rather than returning an unrelated baseline. Do not treat the starter or these notes as a finished reproduction.

## Task-specific evaluation

Dataset: **generated-dates**. Model contract: **Date-token sequences -> decoded date-token sequences**. Metric: **exact_match**, direction **maximize**. Split unique underlying dates before formatting; exact full-string match.

Requested goal: 0.95. This is aspirational, not a verified or calibrated passing threshold.



## Required ablation

Remove attention while keeping encoder decoder and date splits fixed. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
