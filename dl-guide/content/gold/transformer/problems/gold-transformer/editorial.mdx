# Transformer: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}_{\mathrm{keys}}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V
\end{aligned}
$$

Here Q/K/V are query/key/value matrices, d-k the key width, and M an additive mask with zero for allowed keys and negative infinity for blocked keys. Fully blocked rows require an explicit zero-output convention rather than an undefined softmax.

derive numerically stable scaled dot-product attention and explicit mask semantics. Compute scaled query-key scores, add the mask, normalize over keys, and form the weighted sum of values as shown above. Do not softmax over queries or scale by sequence length. Support different query/key lengths and value widths. Boolean True allows a key (unlike some other PyTorch mask APIs); additive masks typically contain zero and negative infinity. A fully blocked row needs zero output instead of NaN. No positional encoding, projections, multi-head wrapper, feed-forward block or translation training is claimed by this isolated attention lab.

Read [Attention Is All You Need](https://arxiv.org/abs/1706.03762) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

A bounded executable reference is provided. Imports and model classes live inside solve(data) so a learner can copy the function into the editable notebook cell without hidden helpers. The reference returns dlguide.Submission; the notebook owns P.budget() and grading.

Attention tests compare values and gradients to scaled_dot_product_attention in float64, including non-square sequences and completely masked rows.

## Task-specific evaluation

Dataset: **attention-equivalence**. Model contract: **forward(q,k,v,mask=None) -> attention output**. Metric: **attention_max_error**, direction **minimize**. Compare SDPA values and gradients including non-square and fully masked cases.

No calibrated passing threshold is available.



## Required ablation

Remove the inverse-square-root key-width scale and compare scores and gradient norms. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
