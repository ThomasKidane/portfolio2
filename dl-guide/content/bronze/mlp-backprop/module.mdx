# MLP and backpropagation

## Historical question and bottleneck

[Learning representations by back-propagating errors](https://doi.org/10.1038/323533a0) (Rumelhart et al., 1986) is the primary reference. The original question motivating this module is how to derive NumPy cross-entropy gradients for XOR and a three-arm spiral extension. The practical bottleneck for this exercise is explicit: NumPy analytic gradients agree with central differences; three-arm spirals are an optional generated extension. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`H=tanh(XW1+b1); dZ=(softmax(HW2+b2)-Y)/N; dW1=X^T((dZ W2^T)*(1-H^2)).`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **xor**. Output: **[N,2] -> [N,C] logits**. Optimize or report **accuracy** in the **maximize** direction. NumPy analytic gradients agree with central differences; three-arm spirals are an optional generated extension.

An executable bounded reference and mechanism tests are available; work in the starter before opening the editorial.

## Controlled experiment

Remove the hidden nonlinearity; compare finite-difference gradient errors. Keep split, seed, optimizer schedule and training budget fixed unless that factor is the experimental variable. Report raw quality, wall time and parameter count, not an unsupported superiority claim.
