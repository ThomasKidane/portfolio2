# Compute-budget speedrun capstone: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
\mathrm{throughput}=\frac{U_{\mathrm{completed}}}{t_{\mathrm{elapsed}}},\\ C\le C_0,\quad M_{\mathrm{peak}}\le M_0
\end{aligned}
$$

Here U counts declared work units, t measured wall seconds, C measured compute, and M peak memory; C-zero/M-zero are fixed caps. Compare held-out quality under the same constraints and define whether timing includes compilation, data loading, and evaluation; no benchmark is implied.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Required ablation

Disable each optimization separately and report quality throughput and memory deltas. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
