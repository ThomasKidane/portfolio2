# MLP and backpropagation: derivation and implementation notes

## The mechanism

derive NumPy cross-entropy gradients for XOR and a three-arm spiral extension. For H=tanh(XW1+b1), Z=HW2+b2, subtract the rowwise maximum before log-sum-exp. Cross-entropy gives dZ=(softmax(Z)-one_hot(y))/N, dW2=H.T@dZ and dH=(dZ@W2.T)*(1-H**2). Then dW1=X.T@dH; bias gradients sum over examples. The NumPy reference central-difference-checks one element of each parameter tensor with epsilon 1e-5, trains 160 minibatches, and exports weights into a torch module. XOR needs a nonlinear hidden layer. Three-arm spirals require a separate generated split, not an assertion that the XOR score transfers.

Read [Learning representations by back-propagating errors](https://doi.org/10.1038/323533a0) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

A bounded executable reference is provided. Imports and model classes live inside solve(data) so a learner can copy the function into the editable notebook cell without hidden helpers. The reference returns dlguide.Submission; the notebook owns P.budget() and grading.

Reference training is deliberately bounded. Inspect the mechanism-specific schedule described above and in solution.py; CPU smoke tests establish executability, not convergence or benchmark quality. LeNet and ResNet use 24 Adam minibatches with learning rate 0.01 and clipping at 5.

## Task-specific evaluation

Dataset: **xor**. Model contract: **[N,2] -> [N,C] logits**. Metric: **accuracy**, direction **maximize**. NumPy analytic gradients agree with central differences; three-arm spirals are an optional generated extension.

No calibrated passing threshold is available.



## Required ablation

Remove the hidden nonlinearity; compare finite-difference gradient errors. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
