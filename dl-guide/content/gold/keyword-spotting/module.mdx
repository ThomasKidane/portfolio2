# Log-mel keyword spotting

## Historical question and bottleneck

[Speech Commands: A Dataset for Limited-Vocabulary Speech Recognition](https://arxiv.org/abs/1804.03209) (Warden, 2018) is the primary reference. The original question motivating this module is how to classify Speech Commands with a log-mel CNN using speaker-disjoint published splits. The practical bottleneck for this exercise is explicit: Published speaker-disjoint splits; train-only normalization and silence handling. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`mel_features=log(epsilon+mel_filterbank*abs(STFT(waveform))^2).`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **speech-commands**. Output: **Waveform or log-mel frames -> command logits**. Optimize or report **accuracy** in the **maximize** direction. Published speaker-disjoint splits; train-only normalization and silence handling.

This is a draft skeleton: reference training and task-specific tests are not implemented. The explicit stub must not be mistaken for a finished model.

## Controlled experiment

Replace log-mel features with linear-magnitude spectra at equal frame resolution. Keep split, seed, optimizer schedule and training budget fixed unless that factor is the experimental variable. Report raw quality, wall time and parameter count, not an unsupported superiority claim.

## Pitfalls and checks

- Published speaker-disjoint splits; train-only normalization and silence handling.
- Never fit statistics on validation labels or mix held-out examples into training.
- Check shape and finite outputs before interpreting quality; an unrelated baseline cannot satisfy the intended mechanism.
- Draft targets and safety limits have not been GPU-calibrated. No pass threshold is advertised.
