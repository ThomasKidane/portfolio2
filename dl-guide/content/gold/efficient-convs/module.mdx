# MobileNet and EfficientNet

## Historical question and bottleneck

[MobileNets: Efficient Convolutional Neural Networks for Mobile Vision Applications](https://arxiv.org/abs/1704.04861) (Howard et al., 2017) is the primary reference. The original question motivating this module is how to compare depthwise separable convolutions and compound scaling on CIFAR-100 with explicit FLOP accounting. The practical bottleneck for this exercise is explicit: Report multiply-add convention and measured latency separately from FLOPs. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`Dense cost=H*W*k^2*C_in*C_out; depthwise-plus-pointwise cost=H*W*(k^2*C_in+C_in*C_out).`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **cifar100**. Output: **[N,3,32,32] -> [N,100] logits**. Optimize or report **accuracy** in the **maximize** direction. Report multiply-add convention and measured latency separately from FLOPs.

This is a draft skeleton: reference training and task-specific tests are not implemented. The explicit stub must not be mistaken for a finished model.

## Controlled experiment

Replace depthwise separable blocks by dense convolutions at matched output shapes. Keep split, seed, optimizer schedule and training budget fixed unless that factor is the experimental variable. Report raw quality, wall time and parameter count, not an unsupported superiority claim.

## Pitfalls and checks

- Report multiply-add convention and measured latency separately from FLOPs.
- Never fit statistics on validation labels or mix held-out examples into training.
- Check shape and finite outputs before interpreting quality; an unrelated baseline cannot satisfy the intended mechanism.
- Draft targets and safety limits have not been GPU-calibrated. No pass threshold is advertised.
