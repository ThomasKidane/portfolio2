# Sparse autoencoders

## Historical question and bottleneck

[Towards Monosemanticity: Decomposing Language Models With Dictionary Learning](https://transformer-circuits.pub/2023/monosemantic-features/index.html) (Bricken et al., 2023) is the primary reference. The original question motivating this module is how to fit a sparse dictionary to frozen activations and report reconstruction versus L0 with dead-feature counts. The practical bottleneck for this exercise is explicit: Report L0 reconstruction error dead features and decoder normalization. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

$$
\begin{aligned}
z=\operatorname{ReLU}(W_e(x-b_d)+b_e),\quad\hat x=W_dz+b_d,\\ L=\lVert\hat x-x\rVert_2^2+\lambda\lVert z\rVert_1
\end{aligned}
$$

Here x is a frozen-model activation, z sparse features, W-e/W-d encoder/decoder matrices, b biases, and lambda the sparsity penalty. Average over samples and constrain decoder column norms to prevent trivial rescaling of the L1 penalty.

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **frozen-activation-fixture**. Output: **Frozen activations -> reconstruction and sparse codes**. Optimize or report **reconstruction_mse** in the **minimize** direction. Report L0 reconstruction error dead features and decoder normalization.

This is a draft skeleton: reference training and task-specific tests are not implemented. The explicit stub must not be mistaken for a finished model.

## Controlled experiment

Sweep sparsity penalty at fixed dictionary width and activation sample count. Keep split, seed, optimizer schedule and training budget fixed unless that factor is the experimental variable. Report raw quality, wall time and parameter count, not an unsupported superiority claim.

## Pitfalls and checks

- Report L0 reconstruction error dead features and decoder normalization.
- Never fit statistics on validation labels or mix held-out examples into training.
- Check shape and finite outputs before interpreting quality; an unrelated baseline cannot satisfy the intended mechanism.
- Draft targets and safety limits have not been GPU-calibrated. No pass threshold is advertised.
