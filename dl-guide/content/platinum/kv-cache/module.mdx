# KV cache and speculative decoding

## Historical question and bottleneck

[Fast Inference from Transformers via Speculative Decoding](https://arxiv.org/abs/2211.17192) (Leviathan et al., 2023) is the primary reference. The original question motivating this module is how to implement cached autoregressive decoding and rejection-corrected speculative sampling; audit exactness and tokens per second. The practical bottleneck for this exercise is explicit: Position offsets correct; speculative rejection correction preserves target distribution.
