# GCN and graph attention

## Historical question and bottleneck

[Semi-Supervised Classification with Graph Convolutional Networks](https://arxiv.org/abs/1609.02907) (Kipf and Welling, 2017) is the primary reference. The original question motivating this module is how to implement normalized graph convolution and attention on Cora; aspirational node accuracy 0.81 on a declared split. The practical bottleneck for this exercise is explicit: Declare transductive graph use and fixed public label masks. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`GCN: H_next=sigma(D_hat^-1/2 A_hat D_hat^-1/2 H W). GAT replaces fixed weights by normalized learned edge scores.`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **cora**. Output: **Node features and graph -> node logits**. Optimize or report **node_accuracy** in the **maximize** direction. Declare transductive graph use and fixed public label masks.

This is a draft skeleton: reference training and task-specific tests are not implemented. The explicit stub must not be mistaken for a finished model.

## Controlled experiment

Replace attention with degree normalization at matched hidden width. Keep split, seed, optimizer schedule and training budget fixed unless that factor is the experimental variable. Report raw quality, wall time and parameter count, not an unsupported superiority claim.

## Pitfalls and checks

- Declare transductive graph use and fixed public label masks.
- Never fit statistics on validation labels or mix held-out examples into training.
- Check shape and finite outputs before interpreting quality; an unrelated baseline cannot satisfy the intended mechanism.
- Draft targets and safety limits have not been GPU-calibrated. No pass threshold is advertised.
