# LeNet-5: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
h'=\tanh(W*h+b),\\ p_{ij}=\frac14\sum_{a=0}^{1}\sum_{b=0}^{1}h'_{2i+a,2j+b}
\end{aligned}
$$

Here h is an input feature map, W is a convolution kernel, the star denotes convolution, b in the first line is a bias, and a and b in the sum are spatial offsets. The second line is stride-two average pooling, the teaching adaptation rather than every historical LeNet detail.

compose learned local filters, tanh nonlinearities and spatial averaging into a digit classifier. Use 5x5 convolutions with 6 then 16 channels, average pooling and tanh; flatten a 4x4 pooled map into 120 and 84 hidden units. The reference uses fully connected C3 channels and a linear-logit classifier rather than the original partial-connectivity and RBF output. These deviations are deliberate and must not be presented as an exact historical reproduction.

Read [Gradient-Based Learning Applied to Document Recognition](https://ieeexplore.ieee.org/document/726791) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

A bounded executable reference is provided. Imports and model classes live inside solve(data) so a learner can copy the function into the editable notebook cell without hidden helpers. The reference returns dlguide.Submission; the notebook owns P.budget() and grading.

Reference training is deliberately bounded. Inspect the mechanism-specific schedule described above and in solution.py; CPU smoke tests establish executability, not convergence or benchmark quality. LeNet and ResNet use 24 Adam minibatches with learning rate 0.01 and clipping at 5.

## Task-specific evaluation

Dataset: **mnist**. Model contract: **[N,1,28,28] -> [N,10] logits**. Metric: **accuracy**, direction **maximize**. 5x5 convolution average pooling tanh and bounded MNIST training.

No calibrated passing threshold is available.



## Required ablation

Replace average pooling with max pooling while preserving the training schedule. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
