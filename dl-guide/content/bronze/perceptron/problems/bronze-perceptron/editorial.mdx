# Perceptron: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
\hat y=\arg\max_k(w_k^\top x+b_k),\quad \hat y\ne y:\\ w_y\leftarrow w_y+\eta x,\quad b_y\leftarrow b_y+\eta,\\ w_{\hat y}\leftarrow w_{\hat y}-\eta x,\quad b_{\hat y}\leftarrow b_{\hat y}-\eta
\end{aligned}
$$

Here x is an input, y its true class, and the predicted class maximizes the linear score; w and b are class weights and biases, and eta is the learning rate. Update only on mistakes.

fit separable blobs with the online mistake-driven linear update. Apply the mistake-driven weight and bias updates shown above to the true and predicted classes with opposite signs. Correct examples cause no update. The reference makes eight deterministic passes over at most 128 training examples (at most 1024 updates). A separable training fixture validates the update, not generalization on overlapping blobs.

Read [The Perceptron: A Probabilistic Model for Information Storage and Organization in the Brain](https://doi.org/10.1037/h0042519) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

A bounded executable reference is provided. Imports and model classes live inside solve(data) so a learner can copy the function into the editable notebook cell without hidden helpers. The reference returns dlguide.Submission; the notebook owns P.budget() and grading.

Reference training is deliberately bounded. Inspect the mechanism-specific schedule described above and in solution.py; CPU smoke tests establish executability, not convergence or benchmark quality. LeNet and ResNet use 24 Adam minibatches with learning rate 0.01 and clipping at 5.

## Task-specific evaluation

Dataset: **blobs**. Model contract: **[N,D] -> [N,C] logits**. Metric: **accuracy**, direction **maximize**. Online mistake updates; no autograd required.

No calibrated passing threshold is available.



## Required ablation

Compare raw and averaged iterates with identical example order. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
