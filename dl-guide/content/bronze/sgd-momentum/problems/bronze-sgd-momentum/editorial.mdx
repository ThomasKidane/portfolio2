# SGD with momentum: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
g_t=\nabla L(w_t),\quad v_t=\beta v_{t-1}+g_t,\\ w_{t+1}=w_t-\eta v_t
\end{aligned}
$$

Here L is the loss, w the weights, g the gradient, v the velocity initialized to zero, beta the momentum coefficient, and eta the learning rate. This convention does not multiply the new gradient by one minus beta.

implement velocity updates on an ill-conditioned quadratic and a tiny MLP. Use the velocity and weight updates shown above. Do not multiply the new gradient by one minus the momentum coefficient unless you consistently use that alternative convention. The quadratic control has diagonal curvature (1,20), learning rate 0.03 and 60 steps from (2,2), comparing beta 0 and 0.8. The MLP uses beta 0.9 for 40 full minibatch updates. Record oscillations as well as final objective; momentum is not guaranteed to improve every problem.

Read [Some methods of speeding up the convergence of iteration methods](https://doi.org/10.1016/0041-5553(64)90137-5) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

## Task-specific evaluation

Dataset: **synthetic-classification**. Model contract: **[N,D] -> [N,C] logits**. Metric: **accuracy**, direction **maximize**. Explicit v=beta*v+grad and w-=lr*v; record quadratic objective for beta zero and nonzero.

No calibrated passing threshold is available.



## Required ablation

Set momentum to zero at the same learning rate and compare objective traces. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
