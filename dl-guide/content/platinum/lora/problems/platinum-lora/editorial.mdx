# Low-rank adaptation: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
W_{\mathrm{eff}}=W_0+\frac\alpha r BA,\\ A\in\mathbb R^{r\times d_{\mathrm{in}}},\quad B\in\mathbb R^{d_{\mathrm{out}}\times r},\\ f_{\mathrm{train}}=\frac{P_{\mathrm{trainable}}}{P_{\mathrm{total}}}
\end{aligned}
$$

Here W-zero is frozen, A/B are rank-r adapters, alpha their scale, d-in/d-out layer dimensions, and P parameter counts. State whether biases or other heads are trainable when reporting the fraction.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Required ablation

Compare ranks at fixed trainable-parameter budget. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
