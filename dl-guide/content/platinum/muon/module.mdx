# Muon versus AdamW

## Historical question and bottleneck

[Muon: An optimizer for hidden layers in neural networks](https://kellerjordan.github.io/posts/muon/) (Jordan, 2024) is the primary reference. The original question motivating this module is how to orthogonalize matrix momentum with Newton-Schulz iterations and compare with AdamW under a fixed token budget. The practical bottleneck for this exercise is explicit: Handle rectangular matrices and nonmatrix parameters explicitly; Newton-Schulz finite outputs. This is a reduced teaching adaptation, not a claim that the paper used our dataset or compute budget.

## Mechanism and equations

`momentum=beta*momentum+gradient; update approximately orthogonalizes matrix momentum by Newton-Schulz iterations.`

Derive each tensor's dimensions before implementing the equation. State the normalization axis, numerical stabilizer and train/evaluation behavior. Distinguish a mathematical mechanism from the full original training system.

## Implementation notes

Input/task: **tinyshakespeare**. Output: **[N,T] tokens -> [N,T,V] logits with matrix optimizer**. Optimize or report **bpc** in the **minimize** direction. Handle rectangular matrices and nonmatrix parameters explicitly; Newton-Schulz finite outputs.
