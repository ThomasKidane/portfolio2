# Denoising autoencoder: derivation and implementation notes

## The mechanism

reconstruct clean MNIST from corrupted inputs under a bottleneck parameter budget. Encode flattened MNIST into a 16-unit tanh bottleneck, decode to sigmoid pixel values and reshape to the input image. Corrupt only the input with a seeded 30 percent masking process and train MSE against clean pixels for 48 updates. Ignore MNIST digit class labels. The compact 784-to-16-to-784 network has 25888 parameters; compare clean-target reconstruction under the same evaluation corruption for all ablations. Runtime evaluation must target clean images, not compare output pixels with digit labels.

Read [Extracting and Composing Robust Features with Denoising Autoencoders](https://doi.org/10.1145/1390156.1390294) for the original setting. This lesson and code are independently authored, not copied from that paper's implementation or another guide.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.
2. Set a seed, use only the supplied training split, and keep preprocessing statistics training-only.
3. Validate the local contract before comparing held-out metrics. A contract check is not an accuracy grade.
4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.

## Reference and scope

A bounded executable reference is provided. Imports and model classes live inside solve(data) so a learner can copy the function into the editable notebook cell without hidden helpers. The reference returns dlguide.Submission; the notebook owns P.budget() and grading.

Reference training is deliberately bounded. Inspect the mechanism-specific schedule described above and in solution.py; CPU smoke tests establish executability, not convergence or benchmark quality. LeNet and ResNet use 24 Adam minibatches with learning rate 0.01 and clipping at 5.

## Task-specific evaluation

Dataset: **mnist**. Model contract: **[N,1,28,28] -> [N,1,28,28] reconstruction**. Metric: **mse**, direction **minimize**. Train on corrupted clean pairs; metric against clean pixels; fixed 16-unit bottleneck.

No calibrated passing threshold is available.

- [Extracting and Composing Robust Features with Denoising Autoencoders (author-hosted PDF)](https://www.cs.toronto.edu/~larocheh/publications/icml-2008-denoising-autoencoders.pdf) (2008), related component reference.

## Required ablation

Train without corruption; compare reconstruction at equal bottleneck width. Keep the seed, split, training steps and optimizer fixed. Report both quality and compute cost; one run is not statistical evidence.

## Failure modes

- Fitting on validation labels or allowing split overlap invalidates evaluation.
- Matching output shape alone does not establish that the intended mechanism was implemented.
- A small teaching model is not the original full-scale experiment.
