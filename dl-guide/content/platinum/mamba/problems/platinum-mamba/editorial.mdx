# State-space sequence models: derivation and implementation notes

## The mechanism

$$
\begin{aligned}
h_t=\bar A_t h_{t-1}+\bar B_t x_t,\quad y_t=C_t h_t+Dx_t,\\ \bar A_t=\exp(\Delta_t A),\quad\bar B_t=\left(\int_0^{\Delta_t}\exp(sA)\,ds\right)B_t
\end{aligned}
$$

Here h is state, x input, y output, A the continuous state matrix, D a skip coefficient, and Delta/B/C input-dependent selective parameters. Bars denote zero-order-hold discretization; the expression describes the selective state-space core, not the full Mamba block.

## A reproducible approach

1. State the model's input/output shapes and the loss before coding.

4. Run the ablation with identical splits and compute budget; save your observations outside the shared site.
